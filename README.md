# 🎮 Fast Box Game  

A fun and addictive **browser-based speed game** built using **HTML5**, **CSS3**, **Bootstrap**, and **JavaScript**, featuring the iconic **Squid Game theme song (MP3)** for an exciting background vibe.  

Developed by **MirTechSoft**, this game challenges your reflexes as you try to reach higher levels — where each level gets faster and more intense!  

---

## 🧩 About the Game  

**Fast Box Game** is a web-based mini game designed for entertainment and reaction training.  
Players score points by moving or clicking quickly before time runs out.  
When you reach **100 points**, you complete a level — and as you advance, **game speed increases**, making it even more thrilling!  

---

## 🚀 Features  

- ⚡ Fast-paced, fun, and addictive gameplay  
- 🎵 Includes **Squid Game background music (MP3)**  
- 💯 Level-based progression (100 score = level up)  
- ⏩ Speed increases with every new level  
- 🧠 Built using **HTML5, CSS3, Bootstrap, and JavaScript**  
- 💻 Best enjoyed on desktop for full experience  
- 📱 Responsive design for multiple devices
